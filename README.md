# 🤖 Multi-AI Chatbot

A chatbot that connects with multiple AI providers (OpenAI, Ollama, OpenRouter, etc.) under one platform.

## 🚀 Features
- 🌟 Multi-provider integration
- 🔄 Automatic fallback between providers
- 📜 Chat history management
- ⚡ Fast local + cloud AI

## 🛠️ Installation
```bash
git clone https://github.com/SyedSohaib2-0/multi-ai-chatbot.git
cd multi-ai-chatbot/backend
npm install
npm run dev
